# Product Management Application - Backend

A RESTful API for managing products, categories, subcategories, and product variants.

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Multer

## Features
- User registration and login
- JWT authentication
- Category management
- Subcategory management
- Product CRUD operations
- Multiple product variants
- Wishlist functionality
- Product image uploads

## Installation

1. Clone the repository:

   git clone https://github.com/nandanaprabhakar/product-management-backend.git

2. Navigate to the project folder:

   cd product-management-backend

3. Install dependencies:

   npm install

4. Configure the environment variables in a `.env` file.

5. Start the server:

   npm start

## Environment Variables

Configure the required environment variables for your MongoDB connection and JWT authentication.
